#### Fieldwork Tasks

Use this repository to track and manage all fieldwork tasks. 

#### Overview

This project serves as a centralized workspace for organizing field assignments, documenting on-site progress, and storing related data or reports. 

#### Folder Structure

* /tasks — Individual task descriptions, checklists, and schedules.
* /reports — Completed field summaries, logs, and findings.
* /data — Raw data, photos, or measurements collected in the field.

#### How to Use

1. **Check Active Tasks:** Browse the /tasks folder or check the repository's **Issues** tab to see open assignments.
2. **Update Progress:** Commit your field notes, logs, or data updates to the appropriate folder.
3. **Submit Reports:** Upload final summaries to /reports once a task is complete.

#### Contributing

* Keep file names clear and include the date (e.g., 2026-11-22-site-inspection.md).
* Create a new branch or pull request when submitting major report updates.
